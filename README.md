# Visualisation of Watch Patterns Using Completion Curves and Genre Preference Dashboards

## Overview
This project explores and visualizes watch patterns from user viewing data. It provides insights into viewing trends, preferences, and behavior through interactive and informative charts created with Python, Pandas, Matplotlib, and Seaborn.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Features
- Completion curve analysis
- Genre preference dashboard
- Viewer engagement insights
- Data visualization
